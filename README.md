# Calculator App

A lightweight calculator web app built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in your browser.

## Deploy through GitHub to get a live URL

1. Push this repository to GitHub (default branch should be `main`).
2. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push any commit to `main` (or run the workflow manually from **Actions**).
4. Wait for the **Deploy Calculator to GitHub Pages** workflow to finish.
5. Your live app URL will be:

```text
https://<your-github-username>.github.io/<your-repo-name>/
```

The workflow also outputs the exact deployed URL in the job environment link after deployment.
